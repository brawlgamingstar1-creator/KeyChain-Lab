# KEYCHAIN ​​​​​​LAB

Generator de llaveros 3D moderny basado en web con view previa 3D a timepo real and exportação a STL, 3MF and GCode.

## ✨ Funkce

- Vista previa 3D v reálném čase
- Přizpůsobení textu
- Více stylů písma
- Nastavitelné rozměry
- Export a STL
- Exportación a 3MF
- Generátor GCode
- Vícejazyčná podpora
- Desrollado con Three.js

## 🌍 Idiomy

- Checo
- anglicky
- Španělština

## 🛠️ Technologie

- HTML5
- CSS3
- JavaScript
- Three.js
- JSZip

## 🚀 Jak používat

1. Otevřete `index.html`
2. Přizpůsobte si tento llavero
3. Export a STL / 3MF / GCode

## 📦 Exportujte formáty

- STL
- 3MF
- GCode

## 🎮 Ovládací prvky

- Arrastrar = Rotar
- Desplazar = Zoom
- Clic derecho = Mr

## ⚠️ Poznámky

Pro dosažení nejlepší kvality tisku rozdělte soubory STL/3MF do sekcí En:
- PrusaSlicer
